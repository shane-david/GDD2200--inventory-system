## Main Quest 1: Inventory System

### Goal 
Code a fully functional inventory system with:
- Equipment slots
- Item categories
- Drag & drop equip flow 
The build will behave like a real game UI

### Requirements
- Character Panel
  - 3 Attributes of this Inventory System are Health, Weight, Attack
- Equipment Inventory
  - This Inventory System contains 5 equipments slots: headwear, backpack, boots, weapon, accessory.
  - There are several example equippable items including: fishing hat, light backpack, jump boots, pocket knife, flashlight, and fishing rod. 
- Item Categories
  - There are three Item Categories in this Inventory System: Equipment, Consumables, Materials
  - Equipment is broken down into 3 subcategories: headwear, backpack, boots
- Inventory Grid + Selected Item Panel
  - This Inventory System has a tabbed organization system. It includes 4 tabs: Gear, Tools, Supplies, Food that each have their own invtory grid displaying their respective items. 
  - The bottom section of the inventory serves as an item description section that shows Name, Description, and Flavor Text for a selected item. 
- Equip Flow (Drag & Drop)
  - This inventory system uses drag and drop to equip and unequip items. 
  - When an item is equipped or unequipped attributes will update live and there is clear feedback for success and failure. 

### Deliverables 
- Unity Project 
- 30 - 90 sec video showing equip/swap/reject + attribute changes
- README.md detailing run steps, controls, credits, and a list of known issues
